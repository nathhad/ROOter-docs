Run scripts from the GUI

Custom Command System

For those that are experienced with Linux scripts there is a way to run ash scripts from the GUI by using the Custom Command feature. Go to the System menu and the Custom Command submenu to do this.

If you are planning to write your own script then click on the Scripts tab.

The New button will clear all text from the box so you ca start fresh. To load an existing file you must enter the name in the Script Name line and the path in the Path to Script line then click on Load. To save the newly created file nter the name in the Script Name line and the path in the Path to Script line then click on the Save button. To delete the file nter the name in the Script Name line and the path in the Path to Script line then click on Delete.

Once you have created a script or know the location of a script then select the Configure tab.

Add your new command by clicking on the ADD button. Enter the needed information and click on Save&Apply;.

After this going to the Dashboard tab will show you all the custom commands you have created.

Click on RUN to execute your script.
