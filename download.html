ROOter Autobuilds Firmware

All firmware downloads are now being done using the ROOter Autobuilds. These are firmware created every week and contain all the features and bug fixes that have been applied to ROOter. By doing this ROOter firmware is always up to date, unlike the previous point release. This is not Beta firmware but is fully tested and is used by the ROOter team. The firmware is constantly being improved and the Autobuilds gives you the chance to use this firmware.
