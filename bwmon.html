Per-Device Bandwidth Monitoring

Unless you have an unlimited bandwidth plan with you Provider you will want to know exactly how much bandwidth is being used every month and who is using it. ROOter has a per-device bandwidth monitor that can tell you just that. Go to the Bandwidth Monitor menu and the ROOter Bandwidth Monitor submenu to see the data usage.

The data usage information is updated every 5 minutes and is backed up so that a reboot does not lose any data. The amounts are cleared on the first of the month.

Devices that receive an IP Address from the router via DHCP will have their device name shown. Devices with a static IP Address will show as a *.
